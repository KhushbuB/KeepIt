# KeepIT API Documentation

This repository contains API documentation for **KeepIT**, a lightweight digital archive manager designed for small organizations.

KeepIT uses a simple REST API and JSON data format to help teams manage digital collections and archive items without complex database setup.

## Live Document Link

[KeepIt Service Documentation](https://khushbub.github.io/KeepIt/)

## About This Project

This documentation is a portfolio project created as part of an API Documentation course. It covers the KeepIT REST API, which has two core resources: **Collections** and **Items**.

- API overview and key concepts
- Endpoint reference for Collections and Items
- Request and response examples
